# Mundo Ciclismo 🚴‍♂️💨

Un sitio web moderno, interactivo y responsivo dedicado a la pasión del ciclismo de ruta profesional. Este proyecto incluye información sobre las Grandes Vueltas del calendario UCI, los perfiles de los corredores más dominantes de la era moderna y las escuadras más interesantes del WorldTour.

## 📦 Contenido del Proyecto

El proyecto está compuesto por los siguientes archivos fundamentales:

*   **`index.html`**: Contiene la estructura semántica completa del sitio web. Organizado en secciones clave como Inicio, Grandes Vueltas, Corredores (pestañas interactivas) y Equipos.
*   **`styles.css`**: Define la hoja de estilos global con variables CSS para el manejo del tema oscuro (`#1a1a1a`) y los colores icónicos de las tres Grandes Vueltas (Amarillo Tour, Rosa Giro y Rojo Vuelta). Incluye soporte responsivo para dispositivos móviles.
*   **`script.js`**: Implementa la lógica interactiva utilizando JavaScript plano (Vanilla JS) para el control dinámico del panel de pestañas sin dependencias externas.

## 🚀 Características Técnicas

1.  **Diseño Responsivo (Mobile-First adaptativo):** El menú de navegación, las tarjetas en rejilla (*Grid*) y el contenedor de pestañas se reestructuran automáticamente para pantallas de smartphones y tablets.
2.  **Sistema de Pestañas Interactivo:** Navegación fluida entre perfiles de ciclistas con animaciones de desvanecimiento estéticas (*fade-in*).
3.  **Arquitectura Modular con Variables CSS:** Facilidad para cambiar colores corporativos, fuentes y transiciones desde un único punto en la raíz del documento.
4.  **Estética Profesional:** Sombras suaves, transiciones fluidas en los estados de hover de los botones/tarjetas y un banner *Hero* con efecto degradado de alto contraste.

## 🛠️ Cómo Ejecutar el Proyecto Localmente

Para visualizar y trabajar en este proyecto en tu entorno local, sigue estos sencillos pasos:

1.  **Descargar y Extraer:** Descarga el archivo `.zip` del proyecto y extrae su contenido en una carpeta de tu ordenador.
2.  **Estructura de Archivos:** Asegúrate de que los tres archivos (`index.html`, `styles.css` y `script.js`) se encuentren en el mismo nivel jerárquico (la misma carpeta).
3.  **Abrir el Sitio:** Haz doble clic sobre el archivo `index.html` para abrirlo en cualquier navegador web moderno (Google Chrome, Firefox, Microsoft Edge, Safari, etc.).
4.  *(Opcional)* Si utilizas un editor de código como **Visual Studio Code**, te recomendamos usar la extensión **Live Server** para previsualizar los cambios en tiempo real con recarga automática.
